# OMR private workspace

## Platform and stack
Web, used on desktop and mobile. Next.js on Vercel with a separate Python engine,
Neon Free and Private Blob. These are explicit choices in the approved plan.

## Users and purpose
One owner, usually checking students' 100-question, five-option answer sheets.
Choose or photograph A, optionally B of the same sheet; read CNN v3, review marks,
enter the real exam key, and export scores. The key is separate from training labels.

## Constraints and evidence
Free services only. No signup. Password and 12-hour sessions. Images accessible
for seven days, deleted in the next daily cleanup; answers retained until deleted.
Preserve v3 policy and weights, leave v4 paused, and never add photos or change
dataset pairs. Four Preview parity checks passed; this is not independent accuracy.
All 100 answers require human confirmation before a score is final.

## Voice and identity
Thai, direct, instructive without technical jargon in the user flow. Preserve the
existing green identity. Developer diagnostics belong in a separate owner view.
