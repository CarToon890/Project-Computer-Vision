# โมเดล CNN หลังฝึกเพิ่ม รอบ 26 ต.ค. 2026

ฝึกบน CPU สำเร็จ 12 epochs ใช้เวลา 136.7 วินาที เลือก checkpoint epoch 9 ด้วย Validation
น้ำหนักเดิมที่ `models/row_cnn.pt` และคำตอบยืนยันเดิมยังเก็บครบ ไม่ถูกเขียนทับ

## ข้อมูลที่ใช้

- Train: 3,259 คำตอบยืนยัน จาก 178 แผ่น รวมภาพตัด A/B 6,518 แถว
- Validation: 400 คำตอบยืนยัน จาก 30 แผ่น รวมภาพตัด 800 แถว
- Test: 10 แผ่นเดิม 1,000 ข้อ รวมภาพตัด 2,000 แถว
- จัดแนวภาพที่ใช้ครบ 436 ภาพ มี cache และ SHA256 ตรวจสอบย้อนกลับได้
- ไม่ใช้ร่าง OMR/CNN เป็นเป้าหมายการฝึก และไม่ย้าย Test ไป Train

## การเลือกโมเดล

เลือก checkpoint ด้วยจำนวนข้อถูกของภาพ A บน Validation ก่อน ตามด้วย A-then-B
จำนวนผิดที่ระบบยอมตอบ และ Validation loss
โมเดลเดิมเป็นตัวเลือก epoch 0 เพื่อไม่บังคับใช้ checkpoint ที่ด้อยกว่า
รอบนี้ Validation ภาพ A เพิ่มจาก 392 เป็น 399 จาก 400 ข้อ
cutoff รุ่นใหม่ 0.557031512260437 เลือกจาก Validation โดยตั้ง precision เป้าหมาย 99%
เขียน `selection.json` และน้ำหนักก่อนประเมิน Test ไม่ใช้ผล Test เลือก checkpoint

## ผล Test เดิม 1,000 ข้อ

- น้ำหนักเดิม + cutoff เดิม บน preprocessing ล่าสุด: A ถูก 934 รอตรวจ 66 ผิดที่ยอมตอบ 0
  และ A-then-B ถูก 993 รอตรวจ 7 ผิดที่ยอมตอบ 0
- น้ำหนักเดิม + cutoff ปรับจาก Validation ปัจจุบัน: A ถูก 987 รอตรวจ 12 ผิดที่ยอมตอบ 1
  และ A-then-B ถูก 998 รอตรวจ 1 ผิดที่ยอมตอบ 1
- น้ำหนักใหม่ + cutoff ปรับจาก Validation ปัจจุบัน: A ถูก 998 รอตรวจ 2 ผิดที่ยอมตอบ 0
  และ A-then-B ถูก 999 รอตรวจ 1 ผิดที่ยอมตอบ 0

ดังนั้นผลภาพเดียวของรุ่นใหม่คือ 99.8% และ A-then-B คือ 99.9% โดยนับข้อรอตรวจในตัวหาร
ข้อที่ยังรอตรวจใน A-then-B คือ S0022 ข้อ 85 ซึ่งคำตอบอ้างอิงเป็นเว้นว่าง
การรายงานแยกรุ่นเดิมที่ปรับ cutoff แสดงว่าผลดีขึ้นจากทั้งการฝึกและการปรับเกณฑ์
ตัวเลข A ของน้ำหนักเดิมต่างจากผลย้อนหลัง 93.1% เป็น 93.4% เพราะรอบนี้แก้ preprocessing
แล้วประเมินน้ำหนักเดิมซ้ำบนขั้นตอนเดียวกับรุ่นใหม่ เพื่อให้เปรียบเทียบอย่างสอดคล้องกัน

นี่เป็น assisted development retest ของ Test เดิมที่เคยวิเคราะห์ไปแล้ว
ยังไม่ใช่การทดสอบอิสระหรือความแม่นยำบนข้อมูลทั้ง 270 แผ่น
Train มี blank/multiple อย่างละสองข้อ และไม่มี ambiguous จึงยังมีข้อจำกัดกับคลาสพิเศษ

## ใช้อ่านภาพด้วยรุ่นใหม่

เปิด PowerShell ที่โฟลเดอร์โปรเจกต์:

```powershell
.\tools\read_model_sheet.ps1 -Sheet S0035 -ModelDir models/retrained_v2
```

ผลอยู่ `presentation_build/model_inference_v2/S0035/report.html`
หากไม่ระบุ `-ModelDir` ตัวเปิดเดิมยังใช้โมเดล baseline เพื่อเก็บผลย้อนหลังให้เปิดซ้ำได้
ทุกคำตอบจากการอ่านยังเป็นร่าง ไม่ได้เขียนกลับเป็นคำตอบที่คนตรวจแล้ว

ไฟล์ `row_cnn.pt` และ `model_config.json` ในโฟลเดอร์นี้พร้อมนำไปเชื่อมระบบใช้งาน
ส่วน `evaluation.json`, `selection.json` และ `provenance.json` เก็บผลและที่มา
ชุดรันและผลทั้งหมดอยู่ `presentation_build/retraining_v2/` และมีโน้ตบุ๊ก Kaggle สำรอง
รอบนี้รันบนเครื่องเสร็จแล้ว ไม่จำเป็นต้องรัน Kaggle ซ้ำ
