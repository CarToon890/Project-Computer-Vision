# โมเดล CNN ที่เทรนแล้ว

รับ `row_cnn.pt` จาก Kaggle เมื่อ 26 ต.ค. 2026 และเก็บสำเนาในโฟลเดอร์นี้
ไฟล์น้ำหนักถูกละเว้นจาก Git ด้วย `*.pt` ส่วน `model_config.json` เก็บคลาส ลำดับคลาส
ขนาดภาพ เกณฑ์คะแนนจาก Validation และ SHA256 สำหรับตรวจไฟล์

โมเดลนี้เทรนด้วยชุดทดลอง 38 แผ่นที่คนตรวจครบ 3,800 ข้อ โดยแบ่ง Train/Validation/Test
ตามแผ่น คำตอบช่วยตรวจด้วย OMR จึงไม่ใช่การประเมินอิสระจากระบบช่วยกรอก
ไม่มีการเทรนใหม่เมื่อโหลดน้ำหนักหรือเรียกตัวอ่านภาพ

## อ่านภาพที่จับคู่ยืนยันแล้ว

บนเครื่องนี้ เปิด PowerShell ที่โฟลเดอร์โปรเจกต์แล้วเรียก:

```powershell
.\tools\read_model_sheet.ps1 -Sheet S0035
```

ตัวเรียกใช้ Python ที่ติดตั้งใน Codex และแพ็กเกจภายใน `.local_model_deps` / `.local_cv_deps`
หากใช้ Python ของตนเอง ต้องมี torch, numpy, opencv-python และ Pillow แล้วเรียก:

```text
python src/omr_inference.py --data-root . --model-dir models --sheet S0035 --output-dir presentation_build/model_inference/S0035
```

ผลอยู่ใน `presentation_build/model_inference/<sheet_id>/`:

- `report.html`: แสดงรอยฝนและคำตอบร่าง เปิดดูเฉพาะข้อที่ต้องดูหรือครบ 100 ข้อได้
- `model_predictions.csv`: คำตอบร่าง พร้อมคะแนน แหล่งภาพ และเหตุผลที่ต้องดู
- `summary.json`: จำนวนคำตอบ การจัดแนวภาพ ข้อผิดพลาด และตัวระบุน้ำหนักโมเดล
- `A_registered.jpg`, `A_rows.jpg` และไฟล์ B เมื่อระบบใช้ภาพ B

ใช้คำตอบ A เมื่อผ่านเกณฑ์ หากไม่ผ่านจึงใช้ B มิฉะนั้นรอตรวจ ภาพ B อาจไม่ได้อ่าน
เมื่อ A ผ่านครบทุกข้อ จึงยังตรวจความตรงกัน A/B ทุกข้อไม่ได้ คลาสเว้นว่างและหลายช่อง
มีตัวอย่างฝึกจำกัด ต้องดูรอยฝนเพิ่ม แม้คะแนนโมเดลสูง

คำตอบทุกข้อยังเป็น `model_draft` และ `reviewed_by_human=False`
ตัวอ่านไม่เขียนคำตอบลง `answer_labels.csv` และไม่ใช้คำตอบจริงขณะทำนาย
ผลทดลองแต่ละแผ่นไม่ใช่การรับรองว่าระบบอ่านครบชุด 270 แผ่นแล้ว
