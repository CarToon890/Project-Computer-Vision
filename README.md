# OMR จากภาพถ่ายสมาร์ตโฟน

ภาษาไทย | [English](README.en.md)

โครงงานนี้พัฒนาระบบอ่านรอยฝนบนกระดาษคำตอบ 100 ข้อจากภาพถ่ายมือถือ เพื่อลดงานตรวจด้วยมือ ระบบเปรียบเทียบวิธีวิเคราะห์พื้นที่รอยฝนแบบ CLA กับโมเดล CNN และช่วยให้ผู้ใช้ตรวจข้อที่มีความเสี่ยงก่อนคิดคะแนน

## ทดลองใช้งาน

- **เว็บสาธิต:** [เปิดเว็บ OMR](https://omr-project-demo.vercel.app) แล้วเลือกภาพตัวอย่างที่สร้างขึ้น กดอ่านคำตอบ ตรวจผล และทดลองส่งออก CSV ดูขั้นตอนและข้อจำกัดใน [คู่มือสาธิต](DEMO_RUNBOOK.md) การให้บริการและโควตาอาจเปลี่ยนแปลงได้
- **ใช้งานในเครื่อง Windows:** ดู [คู่มือใช้งาน](APP_RUNBOOK.md) ก่อนเปิด `start_omr.cmd` ตัวเปิดต้องใช้ Python runtime และ dependency ในเครื่อง รวมทั้งโมเดลและข้อมูลอ้างอิงที่ไม่ได้อยู่ใน Git; clone อย่างเดียวจึงยังไม่พร้อมอ่านภาพจริง
- **พัฒนาต่อ:** อ่าน [แนวทางร่วมพัฒนา](CONTRIBUTING.md) สำหรับ dependency และคำสั่งทดสอบ

## ระบบทำงานอย่างไร

1. รับภาพ A ของกระดาษ และภาพ B ของแผ่นเดียวกันได้ตามต้องการ
2. จัดแนวแบบฟอร์มและอ่านรอยฝนด้วย CLA และ CNN
3. แสดงคำตอบที่เสนอและข้อที่ควรตรวจ ให้ผู้ใช้ยืนยันหรือแก้ไข
4. เลือกเฉลย คำนวณคะแนน และส่งออกผล โดยแยกผลโมเดลจากคำตอบที่คนตรวจ

คำตอบจากโมเดลเป็นเพียงข้อเสนอ แม้ระบบไม่แจ้งเตือนก็อาจผิดได้ ควรตรวจและยืนยันทุกข้อก่อนใช้คะแนนตัดสินผลสอบ

## ข้อมูลและข้อจำกัดของผลประเมิน

ภาพถ่ายกระดาษต้นฉบับและไฟล์น้ำหนักโมเดลไม่รวมใน Git แต่ repository **มี** ชุดคำตอบ ข้อมูลผู้ร่วมจัดทำ และไฟล์ตรวจบางส่วนใน [ชุดทดสอบ 39 แผ่น](data/dataset_v2_test39/README.md) ชุดนี้รวมแผ่นที่เคยใช้ประเมินและคำตอบบางส่วนที่รับร่างจากโมเดลเป็นกลุ่ม จึงไม่ใช่ชุดทดสอบอิสระ การรับร่างเป็นกลุ่มไม่ได้หมายความว่าตรวจภาพรายข้อแล้ว

ตัวเลขจากชุดพัฒนาและผลทดสอบภาพสังเคราะห์ไม่ใช่หลักฐานความแม่นยำอิสระบนภาพใหม่ ดู [แผนประเมินอิสระ](INDEPENDENT_EVALUATION_PROTOCOL.md) และ [ผลการฝึก v3](V3_TRAINING_RESULTS.md) สำหรับบริบทและข้อจำกัด

## เอกสาร

ดู [สารบัญรายงานและคู่มือ](DOCUMENTATION.md) สำหรับการใช้งาน การพัฒนา ข้อมูล โมเดล และผลทดลอง ไฟล์รายงานเดิมยังอยู่ตำแหน่งเดิม
